# 抖音同城任意门

把抖音「同城」切换到世界上任何一个城市，看其他国家/城市的同城视频。

## 用法

1. 在 Loon 中安装插件（需开启 HTTPS 解密并信任 Loon CA 证书）。
2. 打开插件详情页，在「城市」配置项中填写目标：
   - 中文名：`巴黎`
   - 英文名：`paris`
   - 直接写经纬度：`48.8566,2.3522`（内置约 90 个世界主要城市，列表外的填经纬度即可）
3. 打开抖音 → 同城，看到的就是目标城市的视频了。
4. 恢复：清空「城市」配置项，脚本自动放行原始请求。

## 原理

MITM 抖音 API 域名（`*.amemv.com`、`*.snssdk.com`、`*.douyin.com`），`http-request` 脚本改写请求 URL 中的 `latitude` / `longitude` 参数。服务器按该坐标返回对应城市的同城视频。

插件使用 Loon 最新语法：`[Argument]` 段定义 `city` 参数，Script v2 以对象形式传入（`$argument.city`）；需 Loon 3.5.1 (983) 及以上版本。

不碰 iOS 定位系统（和系统级改定位是两条路线），iOS 版本无关。

## 注意事项

- 抖音有抓包对抗，部分版本可能证书锁定；如刷不出内容，先关闭插件排查。
- 抖音服务端会参考 IP 归属地：人在国内、定位巴黎，IP 对不上可能被纠正。**跨国切换建议配合目标地区的代理节点**，IP 与定位一致效果最好。
- 抖音更新频繁，接口变化时脚本需要跟进；跑测试：仓库根目录 `npm test`。
